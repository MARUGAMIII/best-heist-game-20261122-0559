Velvet Heist: The Starling Job — a top-down 2D stealth heist game. Play Wren, a thief slipping through three galleries — The Meridian Gallery, The Obsidian Vault, and The Sky Penthouse — dodging guards with raycast vision cones, sweeping security cameras, and a rising alarm meter. Steal paintings, gems, and crack safes; distract guards with coins and smoke, hack cameras, and slip out the exit for a clean getaway. No external libraries, no network requests — pure canvas and WebAudio synth.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the entry output instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
